# Stage 6 — Public-source expansion before client-ready rewrite

調査基準日: 2026-09-16

## Purpose

Client-ready版の全面増補に入る前に、次の4群について公開資料を追加収集・構造化する。

1. R7決算関係資料の現時点で取得可能な範囲
2. 愛媛県「財政事情」5月・11月の時系列
3. 愛媛県の現行公金管理方針・関連規程の公開状況
4. 主要10～15基金の1～5年cash-flowを復元できる公開資料

## Repository policy

第三者が公表したPDF・Word等は、公表されていること自体は再配布許諾を意味しないため、原則として本リポジトリへmirrorしない。公式配布元URL、書誌、取得状況、使える事実、構造化した派生データを保存する。明示的な再配布条件を確認できた場合のみ原本保存を別途検討する。

## Files

- `r7_settlement_public_sources_20260916.csv`: R7決算関連の現在取得可能資料と未公表/未確認項目
- `r7_settlement_availability_note.md`: R7決算資料の利用範囲と更新ポイント
- `finance_affairs_catalog_H14_R8.csv`: 財政事情49号分の公式PDFカタログ
- `finance_affairs_cashflow_findings.md`: 財政事情から得られる基金繰替・資金繰り上の知見
- `public_funds_policy_sources.csv`: 公金管理方針・関連規程の公開状況
- `public_funds_policy_public_status.md`: 現行方針の公開可否と使えるルールの整理
- `major_funds_cashflow_source_register.csv`: R8基金取崩額上位15基金のcash-flow復元用資料
- `major_funds_cashflow_reconstruction.md`: 1～5年cash-flow復元可能性と残るデータギャップ

## Coverage of major funds

R8一般会計の基金繰入32基金351.85764億円のうち、取崩額上位15基金は336.78819億円、95.717%を占める。したがって、1～5年cash-flowの追加調査はこの15基金を優先する。

- R7歳入歳出決算の認定議案は2026-09-09に第397回定例会へ提出済み。
- R7主要施策の成果説明書、R7事後評価は同日公表済み。
- R7の詳細な歳入歳出決算書・決算附属書・財産に関する調書・決算概要説明書・部局別一般会計歳入歳出決算額調書は、2026-09-16時点の公開検索では確認できない。R6ではこれら一式が12月に行政資料として公表されているため、R7も後続公表を追跡対象とする。
- 「財政事情」はH14年5月～R8年5月まで49号を公式ページから追跡可能。
- 愛媛県公金管理方針はR8予算編成方針でも参照されており、現行制度上存在することは確認できるが、最新版本文の独立公開は確認できない。H23包括外部監査には当時の本文が引用されている。
- 上位15基金のうち、年度・複数年度の事業計画からcash-flowを比較的復元しやすい基金と、災害・退職・財政調整等のように支出時期が外生的で公開資料だけでは確定しにくい基金を区別した。
