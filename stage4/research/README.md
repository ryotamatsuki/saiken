# Stage 4 Research Modules

## 自治体の国債・財投債保有急増の背景

- `jgb_purchase_surge_background_20260916.md`
  - 2026年9月13日の日経報道を起点に、地方公共団体部門の国債・財投債保有残高急増の背景を調査。
  - 「確認事実」「本調査の考察」「留保」を分離。
  - 金融政策正常化、日銀国債買入れ減額、国債・預金金利、東京都・武蔵野市・春日井市・兵庫県の実務変化を検証。

関連構造化データ：

- `../processed/jgb_purchase_surge_causal_evidence.csv` — 背景要因ごとの事実・因果評価・確度
- `../processed/jgb_purchase_surge_timeline.csv` — 2024年3月以降の金融政策・自治体運用変化の時系列
- `../sources/jgb_purchase_surge_source_dictionary.csv` — 一次資料・日経記事・既存Stage 3の出典辞書
- `../qa/jgb_purchase_surge_background_audit.md` — 事実／考察分離、統計表現等のQA

### 最終レポートでの使用ルール

1. 「100倍」は購入額ではなく保有残高の比較として記述する。
2. 1.6兆円は地方公共団体部門であり、都道府県だけの値として扱わない。
3. 日銀資金循環統計の地方公共団体保有額は推計・時価系列であることを注記する。
4. 金利上昇、政策変更、自治体の運用方針変更は事実として記述する。
5. 「それらが保有急増を引き起こした」という因果は「本調査の考察」と明示する。
6. 預金金利も上昇しているため、債券優位を自動的に仮定しない。
7. 全国トレンドは愛媛県の目標債券比率には使わず、愛媛県固有のALM制約を先に適用する。
