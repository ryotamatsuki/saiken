## 重要な結論

R6基金総額1,302.28億円を基準とした政策レンジは、保守151.27億円（11.6%）、標準435.32億円（33.4%）、積極574.70億円（44.1%）の債券運用可能額となる。

これは最適比率の断定ではない。標準ケースは過去最大の基金繰替968.01億円を現金・near-cash・1年以内満期債で全額カバーするALM設計である。

R7の基金全体の実際債券残高は、2026-09-15時点の公開資料から確定できないため、R6実績で代替せず、追加債券運用額は未算定とした。
