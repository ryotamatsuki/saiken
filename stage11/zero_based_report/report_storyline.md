# Report Storyline — Zero-Based Public Funds Strategy Review

## Storyline principle

本レポートの中心メッセージは「債券を増やすべきか」ではない。

**愛媛県は基金を大規模な年度内資金繰りにも使っているため、運用高度化の成否は債券比率ではなく、資金を使用時期別に見える化し、その期間に一致する資産へ変換できるかで決まる。**

この主張を、全国比較、愛媛県資金需要、基金別支出、他県管理モデル、市場データ、リスク分析の独立証拠で三角測量する。

## Proposed report architecture

### Executive Summary

結論を5～8点へ圧縮する。購入額の一点推計は出さず、推奨戦略、統計上の規模感、データ制約、実施条件を示す。

### 第1章　愛媛県の課題は「基金不足」ではなく、相対的に大きな基金をほぼ現預金で保有している理由を説明できるかである

- R6全国統一分布
- 愛媛県の基金規模と有価証券比率
- 低比率を非効率と断定しない反証
- 経営上の問いを「比率」から「資金拘束可能期間」へ転換

### 第2章　基金は長期貯蓄だけではなく、毎年度の歳計現金を支える流動性装置として機能している

- R3～R6 16期間分布
- R3～R7借入・返済月
- 季節平均と変動係数
- 7基金への繰替集中
- 「最大需要を365日現金で持つ」ことと「最大需要を支払可能にする」ことの違い

### 第3章　全基金を一律に扱うと誤る――R8取崩の82％は上位7基金に集中し、支出の確度・時期は基金ごとに異なる

- R8取崩集中度
- 財政バッファ、償還、退職、医療、学校、企業立地、施設更新等
- 1年以内・1～3年・3～5年・突発という経済的期間
- 400億円政策バッファと災害救助法定基金の違い

### 第4章　統計上は数百億円規模の期間管理余地が見えるが、公開情報だけでは実行可能額を確定できない

- R6残高－分位点
- 同一年度残高－最大繰替
- 二つの独立方法の収束と限界
- R7詳細決算、週次資金繰り、基金別複数年支出の欠損
- 「統計上の余地」「経済的余地」「実行可能額」の三段階

### 第5章　他県比較が示すのは正しい債券比率ではなく、使用時期を判定して比率を変えられる管理能力である

- R4～R6統一時系列
- R7直接比較の公開制約
- 埼玉、静岡、熊本、東京、兵庫、新潟、香川
- 共通管理能力の抽出

### 第6章　金利正常化で期間対価は復活したが、預金も上昇しており「債券化＝収益改善」ではない

- 預金金利時系列
- 約1年near-date比較
- 2～20年入札利回り
- 期間延長の限界対価
- 実行可能金利差と市場参考値の区別

### 第7章　年限を延ばすほど参考利回りは上がるが、時価感応度も上がる――満期保有を成立させるのは流動性管理である

- 独立3満期構成
- 修正デュレーション
- +25/+50/+100/-50bp
- 再投資リスク
- 満期前売却リスク

### 第8章　戦略は三択である――現時点では「預金高度化＋短中期の段階導入」が最も頑健である

- Option A/B/C比較
- Bを選ぶ理由
- A単独・C即時移行を推奨しない理由
- 固定比率・固定購入額を置かない

### 第9章　運用高度化の第一歩は購入ではなく、13週・12か月・1～5年の資金可視化である

- 管理台帳
- 資金期間区分
- 規程マッピング
- 預金・債券同期間比較
- 月次・四半期・年次レビュー

### 第10章　実施額は毎年度再計算し、予測誤差・満期前売却・実現金利差で拡大又は縮小する

- 算定式
- ストレステスト
- KPI
- 0～3か月、3～12か月、1～3年
- 拡大・縮小条件

### Conclusion

結論を「債券比率」ではなく三つの管理ルールに集約する。
