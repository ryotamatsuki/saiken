# Strategic Options — ゼロベース戦略選択肢

## 1. 選択肢設計の前提

現時点で公開情報から精密な中長期運用額を決めることはできない。一方、(1)基金総額に対して統計上の残余が反復している、(2)主要基金の支出期間が異なる、(3)市場で短期安全資産にも期間対価がある、(4)比較自治体では期間区分・満期分散が実務化されている、という事実は確認できる。

したがって戦略選択肢は「債券を買う／買わない」ではなく、どの程度まで資金管理能力と資産期間を同時に高度化するかで設計する。

## Option A　預金高度化・資金可視化に限定する

### 内容

- 13週・12か月資金繰り予測を整備。
- 普通預金・定期預金の期間区分と競争的引合いを強化。
- 債券運用は現行範囲を維持し、新規の中長期化は行わない。

### 利点

- 最も高い流動性。
- 金利上昇時の評価損説明がほぼ不要。
- 実施負担が比較的小さい。
- 現行方針の詳細が未確認でも着手しやすい。

### 弱点

- 1年以上使用しない資金が存在する場合、期間対価を取り逃す。
- 金利低下局面で預金金利が低下すれば収益が急速に縮小し得る。
- 基金別の複数年工程を資産側へ反映するALM能力が育ちにくい。

### 採用が合理的になる条件

- 週次資金需要が想定以上に大きい。
- 現行公金管理方針が債券年限を厳しく制約する。
- 実際の自治体預金引合い金利と債券利回りの差が小さい。
- 運用事務コストが追加収益を上回る。

## Option B　流動性先行・短中期債の段階導入

### 内容

- Option Aの資金可視化・預金高度化を全て実施。
- 1年以内、1～3年、3～5年の支出時期を基金別に登録。
- 支払前に満期が来ることを説明できる資金から短中期債を段階導入。
- 購入時期を分散し、毎四半期に流動性・時価・予測誤差を確認。
- 固定の債券比率目標を設定しない。

### 利点

- 流動性を維持しながら期間対価を一部取り込める。
- 施設整備・県債償還等の複数年工程と相性がよい。
- 予測能力の改善と資産運用を同じプロジェクトで進められる。
- 満期前売却リスクを管理しやすい。

### 弱点

- 基金別台帳、満期管理、時価把握、報告事務が必要。
- 金利上昇時には含み損が発生し得る。
- 現行方針の具体制約を購入前に確認する必要がある。

### 採用条件

- 13週予測を運用開始できる。
- 主要基金の12か月～5年支出を一定精度で整理できる。
- 対象商品・年限・権限が現行規程と整合する。

## Option C　一括ALM・中長期ラダーへの本格移行

### 内容

- 基金・歳計現金を横断した統合的な資金管理。
- 1年以内～10年以上の複数年ラダー。
- 商品・発行体・年限上限を含む年度投資計画。
- 専門会議体、時価・リスク指標、例外売却ルールを整備。

### 利点

- 長期余資を体系的に活用できる。
- 金利低下時の再投資リスクを分散できる。
- 支払準備資金の最適化余地が大きい。

### 弱点

- 現在公開確認できない基金別現金残高・将来支出・既存満期分布が必要。
- 組織能力、規程、システム、説明責任の要求水準が高い。
- 資金予測が弱いまま長期化すると、含み損時の強制売却リスクが高まる。

### 採用条件

- 週次・月次予測誤差が一定期間安定。
- 主要基金の複数年支出が定常的に更新される。
- 短中期の試行運用で満期前売却・重大例外が発生していない。
- 現行方針・組織・報告制度が長期運用に対応。

## 2. 選択肢比較

5段階の相対評価は意思決定を可視化するための分析上の目安であり、法的評価ではない。

| 評価軸 | Option A 預金高度化 | Option B 段階導入 | Option C 本格ALM |
|---|---|---|---|
| 元本安全性 | 高 | 高（安全債前提） | 高（安全債前提） |
| 即時流動性 | 最も高い | 高い | 設計依存 |
| 収益改善余地 | 小～中 | 中 | 中～大 |
| 金利時価変動 | 小 | 中 | 大きくなり得る |
| 再投資リスク | 高め | 分散可能 | 分散しやすい |
| 実施難易度 | 低 | 中 | 高 |
| データ要求 | 中 | 中～高 | 高 |
| 規程・統治要求 | 低～中 | 中 | 高 |
| 現時点データとの整合 | 高 | 高 | 低～中 |
| 将来拡張性 | 低 | 高 | 高 |

## 3. 推奨戦略

**Option B「流動性先行・短中期債の段階導入」を推奨する。**

ただしOption Aを否定するのではなく、預金高度化をOption Bの第一層として組み込む。Option Cは否定せず、データと運用実績が揃った後の到達像とする。

推奨理由は次の五点である。

1. 統計上、常時全基金を年度内流動性として保持する必要性は確認できない。
2. 一方で基金が資金繰りへ大規模に利用されており、急速な長期化は危険である。
3. 主要基金には1～5年工程を持つものがあり、満期対応の余地がある。
4. 預金金利も上昇しており、債券への全面シフトを急ぐ必要はない。
5. 他県の共通点は高比率ではなく、期間判定・満期分散・年度計画という管理能力にある。

## 4. 推奨しない選択肢と理由

### Option A単独を最終像としない

現在の高い流動性を維持できる一方、複数年使用しない資金の期間対価やALM能力の改善余地を閉じるためである。ただし実際の金利差・事務コスト次第では、個別年度にAへ戻ることを許容する。

### Option Cへ直ちに移行しない

R7基金別現金残高、週次予測誤差、既存有価証券満期分布、現行公金管理方針全文が不足しており、長期化可能額の説明責任を十分に果たせないためである。

## 5. 実施の三段階

### 0～3か月：資金を見える化する

- 主要基金の現金・非現金資産を分離。
- 13週資金繰り予測を作成。
- 12か月・1～5年支出台帳を作成。
- 現行方針の商品・年限・発行体・売却・権限をマッピング。
- 預金引合いの実勢金利を期間別に記録。

### 3～12か月：短中期で試行する

- 使用時期が明確な資金だけを候補化。
- 購入を複数回へ分散。
- 短期・1～3年・3～5年中心で試行。
- 月次で資金予測、四半期で時価・満期・収益を確認。

### 1～3年：実績で拡大又は縮小する

- 予測誤差と満期前売却実績を評価。
- 複数年余資の安定性を確認。
- 必要な場合のみ5年以上の年限を拡大。
- データが悪化すれば預金・短期へ戻す。

## 6. 購入額の決め方

固定的な目標額は設定しない。毎年度、基金ごとに次の式を埋めて合算する。

`期間運用候補額 = 現金残高 - 直近支出 - 確定複数年支出 - 法定/政策留保 - 予測誤差バッファ - 非現金・回転資産調整`

その後、過去第90～95百分位、過去最大、財政・災害ストレスで再検証する。

## 7. 拡大・縮小の判断条件

### 拡大

- 13週予測誤差が安定又は改善。
- 1年以内流動性がストレス水準を十分カバー。
- 満期前売却ゼロ又は例外範囲内。
- 同期間預金との実現金利差が管理コストを上回る。
- 5年以上使用しない資金を個別に説明可能。

### 縮小

- 予測誤差が拡大。
- 予定外取崩が増加。
- 基金残高が減少。
- 大規模事業・災害等で近中期支出が増加。
- 預金金利上昇で期間延長の追加対価が縮小。

## 8. 結論

推奨するのは「債券比率の引上げ」ではなく、**流動性を先に測り、使用時期が分かる資金だけを段階的に期間資産へ変換する管理モデル**である。これなら将来の金利方向や基金残高が変わっても、拡大・縮小を同じルールで判断できる。
