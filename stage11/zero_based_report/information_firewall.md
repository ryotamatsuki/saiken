# Information Firewall — Zero-Based Public Funds Strategy Review

## Purpose

This file establishes the information firewall for Stage 11. The project is an independent zero-based reconstruction based on GitHub-stored data, source registers, and reproducible calculations. It is not a rewrite, extension, validation, or comparison of any prior Ehime consulting report.

## Prohibited sources

The project team must not open, search within, quote, summarize, compare, or use:

- `stage4/reports/ehime_fund_bond_management_consulting_report_R7_R8.md`
- prior Executive Summaries and Conclusions derived from that report
- prior rewrite plans, gap assessments, chapter reviews, quality scores, final reviews, change logs, before/after examples, analytical-depth reviews, or report-specific QA
- prior PR diffs, review comments, or Git history whose purpose is to explain or modify the prior report
- README files whose primary purpose is to state prior report conclusions
- prior recommended amounts, target ratios, maturity ladders, product allocations, or implementation roadmaps as analytical priors

## Permitted sources

The project may use:

- raw or structured CSV/JSON datasets
- public-statistics extracts
- fund-balance, withdrawal, substitution, peer-allocation, and market-rate datasets
- source dictionaries and source registers
- public-source factual extracts, but not prior interpretation/recommendation sections
- reproducible data-processing code, excluding hard-coded prior report conclusions
- public consulting-report benchmark materials solely for analytical writing, exhibit, and storyline techniques

## Independence rule

Any conclusion, numerical range, strategic option, maturity structure, or recommendation must be derived anew from the permitted data room. No prior conclusion is an initial condition or target.

## Known but unusable context

Because this project is being launched after prior work existed in the repository and conversation history, the project cannot truthfully claim that no prior conclusion has ever been seen by the wider ChatGPT session. The independence standard therefore is operational: prior report files and prior report-derived conclusions are not opened, searched, cited, copied, used as priors, or used to tune the new analysis. Any numerical result must be reproducible from permitted Stage 11 inputs.

## External web restriction

The analysis basis is GitHub-stored material. External web research is not to be expanded. A registered primary-source URL may be checked only where necessary to resolve a definition or corrupted/missing source extract; such use must be logged.

## Final QA requirement

`independence_qa.md` must confirm compliance with this firewall. Any prohibited-file access or use of prior report conclusions as analytical inputs results in `ZERO-BASE INDEPENDENCE FAIL`.
