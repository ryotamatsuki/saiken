# Stage 10 — 骨太な分析への全面改訂・実行

## 目的

Stage 9で固定した分析・考察基準を実際の追加分析へ適用し、canonical reportを「判断構造が整ったレポート」から「複数の独立した分析で中心仮説を検証する政策分析レポート」へ深化させる。

本Stageでは、435.32億円を正当化することを目的とせず、月次・季節的資金需要、主要基金の将来支出、運用額別ストレス、満期構成別リスク・収益、他県縦断データ、市場金利の各方向から反証可能にした。

## 主な結論変更

Stage 8の435.32億円は、単一の「標準運用額」から次の二層へ再定義した。

- 債券総額：400～450億円程度を初期検討レンジ
- 1年超に固定する中核資金：280～300億円程度を初期検討域

435.32億円は総債券レンジ内の参考点として残すが、全額を中長期へ固定する額とはしない。

理由は、R6基金総額1,302.27675億円から過去最大基金繰替968.01億円を控除した参考残余が334.26675億円である一方、R8年度末基金残高見込み1,254億円では285.99億円まで低下するためである。

   - R3～R7の基金借入・返済タイミングとR3～R6の金額分布を接続。
   - 年度初めと年度末は同程度の高需要でも変動性が異なることを確認。

   - R8取崩額上位15基金（全体の95.717%）を将来支出の確度・時期・突発性で分類。

3. `scenario_comparison.csv` / `liquidity_stress_analysis.md`
   - 300、400、435.32、480、500、600億円の債券総額をR6実績・R8残高見込みで比較。

   - 埼玉、熊本等について複数年度の比率・利回り変化を確認し、「債券比率上昇＝利回り上昇」という単純仮説を反証。

5. `maturity_risk_return_analysis.md` / `maturity_structure_comparison.csv`
   - 短期重視、前倒し、均等、中長期重視の満期構成を、参考利回り・デュレーション近似・金利ショックで比較。

6. `market_term_premium_analysis.md`
   - 1年の預金・国庫短期証券比較と、2年以上の期間延長に伴う参考利回り・リスクの交換条件を整理。

7. `analysis_recompute.py`
   - 主要計算をPythonで再現可能化。

## 読み方

Stage 10の数値は、確認事実と政策モデルを分けている。特に、R8年度末基金残高1,254億円は予算上の見込みであり決算値ではない。また、1年超280～300億円は現時点の公開情報から導く初期検討域であり、現行愛媛県の運用方針又は最適値ではない。
