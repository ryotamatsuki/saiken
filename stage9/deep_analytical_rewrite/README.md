# Stage 9 — 骨太な分析・考察への深化

## 1. 目的

Stage 8で整えた意思決定の骨格を維持しながら、canonical reportの第4～13章を中心に、分析・考察の深度を一段引き上げるための改訂設計を作成する。

今回の中心課題は文章量ではない。各主要論点について、

`公表資料 → 確認事実 → 特徴・パターン → 原因・メカニズム → 反対仮説 → 愛媛県固有の含意 → 判断 → 見直し条件`

までを具体的に言語化することである。

## 2. このStageで行うこと

- McKinsey、BCG、Deloitte、PwC、EY、Accenture、Oliver Wymanの公開レポートから、分析・考察を文章へ変換する方法を抽出する。
- その方法を、行政・財政担当者が自然に読める日本語の執筆基準へ変換する。
- canonical reportの第4～13章を節単位で監査し、「事実説明で止まっている箇所」「原因分析が薄い箇所」「反証が不足する箇所」を特定する。
- 第9～12章を中心に、新規分析を追加すべき箇所と、既存データから考察を深めるだけで足りる箇所を分ける。
- Before / After例を作り、次段階の本文改訂で求める分析密度を固定する。

## 3. 今回はcanonical reportを変更しない

Stage 9前半は設計工程である。`stage4/reports/ehime_fund_bond_management_consulting_report_R7_R8.md` は変更しない。

本文改訂は、本Stageで定める分析文章標準、章別監査、追加分析計画を確定した後に別工程で実施する。

## 4. 主要成果物

- `consulting_analytical_writing_standard.md` — 一流コンサルの論証方法を日本語の実務基準へ変換

## 5. 現時点の診断

Stage 8稿は、意思決定の構造、シナリオの条件、リスク管理、実施工程は大きく改善している。一方、分析文章の密度は章によって差があり、特に次が弱い。

1. 他県との差を生む原因・管理能力の説明。
2. 愛媛県の基金繰替がなぜその季節性を持つのかという資金収支上のメカニズム。
3. P75、P90、最大値を政策判断へ使い分ける理論的意味。
4. 435.32億円を独立した複数の方法で検証する分析。
5. 基金別に「いつまで拘束できるか」を年度別の将来支出へ接続する分析。
6. 金利差を収益だけでなく流動性・時価・再投資リスクとの交換条件として説明する分析。
7. リスクがどの経路で損失又は資金不足へつながるかという因果説明。

## 6. 日本語方針

本文では原則として日本語を使用する。

例：

- liquidity → 流動性
- cash forecast → 資金繰り予測
- investable amount → 運用可能額
- maturity → 満期・残存期間
- governance → 管理体制
- trigger → 見直し条件
- peer → 比較対象自治体
- capability gap → 管理能力・制度面の差

ALM、KPI、デュレーション、ラダー等、実務上定着している用語は初出時に日本語を併記する。
