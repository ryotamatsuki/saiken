# 兵庫県reference case — 長短資金の分離と広い年限分散

**基準時点:** 令和7年度資金運用実績・令和8年度計画 / 2026-09-16確認  
**位置づけ:** 6コアケースを補完するmaturity / governance reference

## Fact

令和7年度の基金運用は一日平均で短期5,689億円（平均利回り0.549%）、債券等2,239億円（0.839%）、合計7,928億円（0.631%）。繰替運用可能基金では短期5,518億円、債券等2,239億円、合計7,757億円であった。

令和8年度計画では、繰替運用可能基金について歳計現金不足への繰替運用を継続しつつ、余資は預金へシフトし、債券は歳計現金収支・金利動向に配慮し計画的に運用するとしている。R8新規購入計画案は2・3年250億円、5年250億円、10年100億円、20年40億円、30年15億円の計655億円。県は資金運用指針、年度運用方針、資金管理委員会及び年度実績・計画を継続公表している。

## Interpretation

兵庫は、基金を歳計現金への繰替に使いながら、残余について2～30年まで複数年限へ分散する実例である。愛媛と同様にcash managementとの結び付きが強い一方、長期資産を完全に排除していない点が参考になる。

## Ehime implication

第11章では「繰替需要がある自治体でも、全基金を短期に固定する必要はなく、負債側の時間軸を分離できれば中長期ラダーが可能」という外部caseとして使用できる。第14章では資金管理委員会・指針・年度計画・実績公表の組合せをgovernance referenceにできる。

## Limitation

兵庫の30年債購入計画は兵庫固有の資金構造・規程・管理能力に基づく。愛媛の初期portfolioで10年超を採用すべき根拠にはならない。
