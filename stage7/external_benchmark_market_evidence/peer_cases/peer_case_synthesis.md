# Peer Case Synthesis

## 1. 結論

6都県＋兵庫referenceを比較すると、優れた公金運用に共通するのは「債券比率が高いこと」ではなく、**cash-flowを把握し、流動性を先に確保し、その外側に年限分散したportfolioを置き、年度計画・limit・reviewで統制すること**である。

## 2. 共通するpractice

1. **安全性・流動性が収益性より先**に置かれる。新潟、熊本、東京等で明示的であり、他県の実務もこの順序と整合する。
2. **運用可能期間で商品を変える。** 埼玉は短期=普通預金、中期=定期預金、長期1年超=債券。東京は短期2年以下、中期2～5年、長期5～10年。熊本は預金1年以内、債券21年以内としている。
3. **一括運用は支払準備の重複を減らす手段。** 埼玉、静岡、新潟、熊本、東京の一部で確認できる。
4. **原則満期保有だけでは不十分で、満期をcash-flowへ合わせる。** 熊本はラダー、東京は複合ラダー、兵庫は複数年限への計画購入を採用する。
5. **計画・実績の公表とgovernanceを組み合わせる。** 新潟は年度運用計画＋実績公表、東京は年度計画＋アドバイザリー会議、兵庫は資金管理委員会＋指針＋年度計画を持つ。

## 3. practiceが分かれる論点

### 債券比率

R7の直接比較可能な高債券ケースでも埼玉65.0%、静岡61.7%。一方、東京のR7実績見込みは35%、香川はR6統一統計で0%。これは単一の適正比率がないことを示す。

### 最長年限

東京は10年、熊本は21年、兵庫は30年まで公表例がある。最長年限はrisk appetite、cash-flow、規程、portfolio規模の関数であり、peer maximumをそのまま採用すべきでない。

### 歳計現金との結び付き

香川・兵庫は基金と年度内cash managementの結び付きが強い。東京は基金目的別のliability matchingを強調する。愛媛は基金繰替需要が大きいため、前者のcash-management視点と後者のALM視点を組み合わせる必要がある。

## 4. 愛媛へ移植しやすいpractice

- 13週・12か月・3～5年のcash-flow horizonを分ける。
- immediate liquidity / short / medium / longのbucketを設ける。
- 複数基金を一体管理する場合でも基金別liability registerを維持する。
- 中長期資金は償還年を分散し、特定年への満期集中を避ける。
- 年度運用計画でeligible assets、maturity、購入予定、例外売却を事前に整理する。
- 四半期又は年次でactual vs planをreviewする。

## 5. 愛媛では慎重に扱うべきpractice

- 埼玉65%、静岡62%、東京43%想定等を目標比率として使用すること。
- 熊本の21年、兵庫の30年をそのまま最長年限とすること。
- 高利回り商品をcash-flow確認前に採用すること。
- 一括運用だけで自動的に余剰資金が増えると仮定すること。
